# Art2UGUI Figma 导出

选中一个顶层 Frame，在插件面板点击“导出 ZIP”。ZIP 包含 `{Frame名}_ui_data.json` 和独立 PNG，使用与 PS 一致的导出协议 v2。

## 使用

- 无全局倍率。节点 `^N` 只控制当前 PNG 的分辨率，不继承给子节点、不改变布局或文字字号。
- 倍率标记从 `*N` 改为 `^N`，旧设计中的 `*0.5` 需改名为 `^0.5` 后重新导出，不保留旧倍率解析。
- 面板提供无/1px/2px 透明留边，默认 1px；启用时至少留 1 个实际透明像素，JSON 保留相应的小数补偿。
- 前缀提示 `btn_`、`img_`，后缀提示 `%`、`~`、`^N`。支持组合，例如 `img_star%~^0.5`。
- `~` 导出白色透明度蒙版及原色；普通 PNG 保留自身颜色，不额外输出 Tint。
- 可见文字输出文字数据；普通组递归。前缀组内部文字和所有前缀图片（含 Tint）从父 PNG 分离，避免重复显示。
- 文字字号与布局包含绝对文字矩阵的缩放；自动宽高文本不自动换行，其他文本框保留自动换行。字号折算后 scaleX/Y 保持 1，不再重复缩放。
- 隐藏和 `#` 子树不生成独立导出项；`#` 子树的可见内容仍可能参与父 PNG。

例如 200×200 图案，`^0.5` 导出 100×100；加 1px 留边得到 102×102，JSON 含边矩形为 204×204，内部图案布局仍为 200×200。

完整字段契约、Unity 升级要求及旧数据边界见 [PS 说明](../Art2UGUI_PS/README.md#与-unity-的导出协议-v2)。Unity 导入包需要同步更新，旧包不能可靠导入新结果。

## 实现与验证

图片在临时副本中渲染到固定大小透明 Frame，保留旋转后的渲染矩形，JSON 图片 rotationZ=0、scaleX/Y=1。副本当前节点透明度归一为 100%，有效祖先透明度写入 JSON，由 Unity 应用一次。UI Canvas 负责整图置白和透明留边，源节点不改颜色、可见性或透明度；临时 Frame 在成功及失败时清理。

```powershell
cd Art2UGUI_Figma
npm ci
npm run check
npm test
npm run build
```

`dist/code.js` 是 manifest 加载的构建产物，需随源码更新。测试覆盖 ZIP、缩图、分数几何、旋转矩形、透明度、父子分离、路径、错误及临时资源清理。真实无头浏览器检查面板消息、PNG 白色像素和透明留边；没有浏览器会明确跳过，可用 `FIGMA_TEST_BROWSER` 指定 Chrome/Edge。

2026-11-13 已通过 15 项自动回归（含真实浏览器）、TypeScript 检查和构建，并通过 PS 两端 JSON 对齐检查。尚未在真实 Figma 客户端执行本次插件；原生渲染、字体、阴影、复杂蒙版、非等比文字变形及旋转/镜像组合仍需客户端验收。
